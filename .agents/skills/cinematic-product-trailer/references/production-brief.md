# Production brief

Write a short `BRIEF.md` and a scene plan before production.

## Required brief fields

- Product and verified description
- Audience
- One job for the trailer
- One idea viewers should remember
- Final action
- Duration and aspect ratio
- Resolution and delivery format
- Sound requirements and sound-off behavior
- Approved assets and visual references
- Exact product claims
- Claims or images that need qualification
- Visual system: color, type, materials, motion character
- Production method and required tools
- Editable-source location

Do not add claims only to fill a scene.

## Scene plan fields

For each named scene, record:

| Field | Purpose |
|---|---|
| Time | Start and end time |
| Job | What the viewer must understand |
| Visible action | What changes on screen over time |
| Text | Exact editable wording |
| Assets | Files or generated elements used |
| Evidence | Source for product claims |
| Sound | Music, effect, or silence cue |
| Exit | How the scene leads to the next one |

## Visual proof

Identify three representative stills and one hardest-moment preview. Record why the selected preview is the highest-risk shot and what must pass before full production.
